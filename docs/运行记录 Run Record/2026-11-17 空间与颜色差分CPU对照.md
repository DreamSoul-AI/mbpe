# 空间与颜色差分 CPU 对照

## 数据与口径

同一 CIFAR-10 和 SVHN 6000 张学习图，沿用 H4 每集 500 张作为配对探索。三个旧对照复用原始 RGB 零阶、原始 RGB 横向一阶、绿色中心横向一阶。输入清单内容和旧词表 SHA-256 均核对。新矩阵是在同一批学习图上分别学习颜色表示和空间阶数，每个最高词表取 20、40、60 万前缀。256 原子另计。H4 保留普通切分和同词表最短切分。

按 H4 选择后封存 60 万词表的条件和哈希，再评估 H6 每集 500 张。样本取自本地官方测试源，按类别均匀，剔除已知旧池和学习样本的索引与像素指纹。H4 选择结果、H6 清单及载荷都在原件目录。方向对照沿用同一 H4，固定按列扫描。

## 原件与复现

本机原件根为 tmp/2026-11-17-difference-orders/。run.py、confirm.py、directions.py、distribution.py、oracle.py 和 analyze.py 保存实际入口。各 stages.json 记录完整命令、PID、阶段时间和退出码。source 与 direction-source 为实际源码快照。confirmation 保存选择封存、H6 清单、逐图长度和独立恢复。analysis.json 保存三档完整配对均值、逐图差区间、残差诊断和资源汇总。
