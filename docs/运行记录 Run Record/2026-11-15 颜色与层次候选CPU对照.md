## 资源与校验

研究进程 Idle 优先级，单逻辑 CPU，线程库各 1、worker 0，一次一个重任务；主入口监控自身 RSS 和系统可用内存，8 GiB/4 GiB 为停止自身作业边界。临时文件在 repo/tmp。资源精确峰值和优先级来自各报告，最终汇总见 final-audit.json。H2 为固定 1000 图、单核有限任务，资源回执同样保存；未终止他人进程。

最终汇总 28 份资源回执，记录到的最高自身 RSS 为 652,804,096 字节（约 0.61 GiB），优先级值均为 Idle 的 64，亲和性均为单核 `[0]`。此为采样记录值，不保证捕获瞬时内存峰值。

H1 共 12 条件×1000 图×2 数据集在测试端独立恢复，共 24,000 次；验证端另 24,000 次。H2 四条件共 8000 次独立恢复。每次先逐图逆变换，再在独立进程仅从字典和 payload 恢复 RGB，并与清单哈希比较。计数不代表不同图片数。

完整离线回归 **76 项通过**，真实数据无损检查另计。运行 tests/run.py 时在 Python 进程内将 TEMP/TMP 和 tempfile.tempdir 指向本任务 test-tmp，避免系统临时目录；单核 Idle，未用 GPU。完整输出留 offline-tests.log。
