# 固定分块的模型输入对照

**在已测图像上，固定分块占用的位置比逐 token 输入的二维 BPE 少。** 第 38 批同一份 32×32 绿通道，4×4 分块为 64 个位置/图，CIFAR-10、SVHN 的二维 BPE 平均为 952.97、926.98。分块数据装入 192 维 BF16 向量后逐图还原。 [第 38 批 BPE 对照](<2026-11-13 第38批 原始像素完整文件对照.md>)

## 输入与操作

- CIFAR-10、SVHN 各用第 38 批冻结的 100 张原始绿通道测试图。读取各自的 `column-0-huffman.decoded`，逐图对回输入清单中的像素 SHA-256。
- MNIST 用 Elsner 定宽对照的 10,000 张 28×28 灰度测试图，IDX 文件的 SHA-256 与原运行记录一致。 [MNIST 定宽运行](<2026-11-14 MNIST BPE 定宽落盘对照.md>)
- 三通道用第 40 批同一份 40 张 16×24×3 CIFAR-10 测试裁块。读取 `rgb/nd-256-huffman.decoded`，逐条对回输入清单的 RGB 格子 SHA-256。 [第 40 批裁块与 BPE](<2026-11-14 第40批 任意形状文件与线性对照.md>)

用仓库现有的 `Patchify` 和 `Reconstruct`。块内像素按原值填到 192 维 BF16 向量的前几维，其余置零。从输入向量取回像素分量，转回 uint8 后按固定块顺序拼成原图。0–255 的整数都可以用 BF16 精确表示。外框和分块布局已知，位置由块顺序确定。ViT 的位置数与此相同，常规可训练投影、位置编码及分类 token 属于具体模型的输入配置。 [分块代码](../../src/mbpe/structure/bpe/patch.py) · [ViT 原论文 §3.1](https://openreview.net/pdf?id=YicbFdNTTy)

## 实际输入张量与缓存估算

输入张量按每位置 192 个 BF16 数计算，每个位置 384 字节。KV 列沿用研究报告假设的 4 层模型，每个位置 3,072 字节，按需分配。模型运行时若另加分类、分隔或形状向量，应将其位置一并计入。

| --- | --- | ---: | ---: | ---: | ---: | ---: |
| CIFAR-10、SVHN 各 100 张绿通道 | 2×2 | 4 | 256 | 98,304 | 786,432 | 200/200 |

对照同一份 RGB 裁块，三维几何 BPE 平均 1,103.65 个内容位置。8×8 RGB 块每个分量占一维，正好用满 192 维。若使用可训练的无偏置线性投影，从 192 维映射到 192 维需 36,864 个参数，占 72 KiB 的 BF16 权重。实测的直接填充映射无需训练参数。显存峰值、学习投影后的还原和下游任务质量待验证。

## 复核

2026-11-14 01:49（Asia/Shanghai），Python 3.13.9、PyTorch 2.14.1+cu130。在 CPU 上用一个逻辑核、Idle 优先级、单计算线程和零数据加载 worker。计时覆盖输入读取和逐图复核，用时约 0.17 秒。核心操作如下，`images` 的形状是 `[样本数, 1, 高, 宽]`，RGB 另有末轴 3。

```python
import math
import torch
from mbpe.structure.bpe.patch import Patchify, Reconstruct

image_shape = tuple(images.shape[2:])
patch_shape = (side, side, *image_shape[2:])
patches = Patchify(patch_shape)(images)
count, positions = patches.shape[:2]
pixel_values = math.prod(patch_shape)
embedding = torch.zeros((count, positions, 192), dtype=torch.bfloat16, device="cpu")
embedding[..., :pixel_values] = patches.reshape(count, positions, pixel_values)
restored_patches = embedding[..., :pixel_values].to(torch.uint8).reshape(patches.shape)
assert torch.equal(Reconstruct(image_shape)(restored_patches), images)
```
