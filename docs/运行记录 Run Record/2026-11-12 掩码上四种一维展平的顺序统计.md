## 说明了什么
1. 只看相邻一格，Hilbert 并不占优：蛇形的相同比例最高、游程最长、看前1格熵最低。Hilbert 的好处不在“走到了上下邻居所以更常相同”。
2. Hilbert 的优势在于往前多看几格时：前2、4格里常包含空间上的上方/左方邻居（曲线折回），所以看前4格时 Hilbert 在所有格子都最低。BPE 合并成多格 token 时，正好吃到这种“前几格里有二维邻居”的结构，这与第29、30批 BPE 实测中 SVHN/CelebA/掩码上 Hilbert 最短一致。
3. 与 2026-11-11 小字母表掩码上限记录对比：红 bin128 二维上下文（左+上+左上+右上）是 0.322，Hilbert 看前4格是 0.430，二维仍比最好一维少约 25%。所以二维的潜在空间还在，但现有二维候选学到的规则几乎全是横向一对，没把这份空间用上；问题更像是“规则形状/合并策略”，而不是“数据里没有二维结构”。
4. 对后续的提示（未执行，仅供参考）：二维方法要和 Hilbert 公平比，至少应能学出纵向与紧凑块规则；评估二维是否有用时，“看前 k 格的熵”在 k=4 时的 Hilbert 数值是一个更难打败的一维基线。
