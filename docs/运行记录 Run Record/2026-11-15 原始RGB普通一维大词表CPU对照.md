# 原始 RGB 普通一维大词表 CPU 对照

## 实际范围和输入

用户明确要求直接原始 RGB，不做差分、不变颜色、不用最短切分，普通一维 BPE 比 15 万/20 万规则。复用 E1 每数据集 1000 学习图、H2 每数据集 1000 测试图。输入 manifest 的 SHA 与上一轮 20 万预算实验完全一致；固定 3×32×32 uint8、按列展开、逐通道共享词表，不跨图合并。未下载数据，未开启 GPU。

实现为 `studies/color_vocab_extension.py --raw-only`，三阶段 `train → evaluate → decode`。先保存协议和源码，再学习全部四个候选并封存，之后读取测试。20 万完整合并表截出 15 万前缀，词条及编号按前缀恒等检查。学习器模型为普通 BPE，无 normalizer、pre-tokenizer 或 added tokens；实际词表数为预算＋256。min_frequency=1，沿用已有 tokenizers 0.22.2、Python 3.13.9、NumPy 2.5.4。

H2 已曝光，本次是按用户要求补齐同输入配对消融，不作为全新未曝光确认。15 万/20 万都在相同学习集建立，没有在测试时调规则、方向或选赢家。

## 结果与还原

| 处理及解析方式 | CIFAR 15万 | CIFAR 20万 | SVHN 15万 | SVHN 20万 |
| --- | ---: | ---: | ---: | ---: |
| 原始 RGB＋普通一维 BPE | 49.26%（1558.803） | 49.79%（1542.402） | 58.13%（1286.345） | 58.65%（1270.206） |
| 左差分＋普通一维 BPE | 56.80%（1327.008） | 57.09%（1318.292） | 69.51%（936.660） | 69.95%（923.131） |
| 颜色变换＋左差分＋普通一维 BPE | 66.47%（1030.179） | 66.95%（1015.177） | 76.65%（717.420） | 76.93%（708.821） |
| 颜色变换＋左差分＋最短切分 | 70.33%（911.339） | 70.84%（895.765） | 79.43%（631.851） | 79.70%（623.700） |

表中减少比例基于 3072 个原始位置，括号为平均 token 数。旧六类结果读取已封存 report 和独立 decode 回执，核对字典哈希；新两档各集逐图恢复原字节。独立解码进程只加载词表、token IDs 和身份哈希，按展开长度推知固定通道/图片边界，不读原始图片，也不需要 counts。四个新条件各 1000 图全部通过。

## 工程和资源验证

新增原值路径绕过所有变换，并提供定向测试：将差分、颜色变换及其逆变换替换成必然抛错的调用，原值路径仍能经按列原子往返；已有 baseline/color 往返保持不变。完整离线回归 **78 项通过**，真实数据的 4000 次独立恢复另计。

实验进程 Idle、单逻辑 CPU、线程库各 1、数据 worker 0；主入口启动前及运行中检查内存，自身 RSS 超过 8 GiB 或系统可用少于 4 GiB 停止自身作业。临时文件本 repo/tmp；测试进程内同时设置 TEMP/TMP 与 tempfile.tempdir。没有结束其他进程，不改官方或 legacy，没有提交推送。三阶段均退出 0，无本轮失败或资源停止。

本机原件根 `tmp/2026-11-15-raw-rgb-200k/`（Git 忽略，未发布）：protocol.json、source、run.py、stages.json、train/evaluate/decode.log、run/sealed.json、run/各数据集/raw-*.json 和 *.npz、report.json、independent-decode.json、offline-tests.log、analysis.json。stages.json 保存真实命令、PID、耗时和退出码，资源回执在 sealed/report/decode 中，运行前冻结的学习及测试身份哈希也在 sealed。旧对照位于 `tmp/2026-11-15-color-200k/run/`。
