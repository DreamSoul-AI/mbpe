# 2026-11-15 RGB一维规则预算扩展CPU对照

## 实际输入和封存

按用户授权，仅做CPU BPE，固定一个token一个192维BF16位置；允许十几万规则，不以CPU时间或词表文件大小为研究失败判据。复用 `tmp/2026-11-14-rgb-capacity` 的各1,000张学习图，以及 `tmp/2026-11-15-autonomous/shared-inputs` 的各1,000张E2测试图，不缩放、不量化、不重新选图。来源数组SHA256和逐图RGB哈希加载时复核，学习只读取学习图；旧测试曾用于E2，因此明确是复用的独立于学习的测试池。

固定左差分、按列扫描、3通道共享256基本符号，不跨样本/通道合并。原子为chr(256+uint8)，不是UTF8字节切分，无normalizer/pretokenizer。tokenizers0.22.2 BpeTrainer最低频次1，最大vocab_size150256；只在学习图训练一次，将前256/1024/4096/16384/65536/100000/150000条分别保存封存，才加载测试指标。各档实际规则数和词条数保留于checkpoint与sealed-before-test.json。

## 真实运行与独立验证

入口为 [rgb_large_vocab_study.py](../../studies/rgb_large_vocab_study.py)。已有Python3.13.9解释器，通过只读追加既有 `D:/anaconda3/Lib/site-packages` 使用之前文本实验同版tokenizers；没有安装、升级或下载。

```powershell
& './third_party/venv_mdbpe/Scripts/python.exe' -B -X utf8 tmp/2026-11-15-rgb-large-vocab-run2/run.py
```

装配程序按 CIFAR run/decode、SVHN run/decode 顺序执行，全部退出0。各run先保存最大词表和全部前缀的摘要，编码阶段每图展开为原始残差并恢复RGB核对哈希。保存uint32 token编号流和每通道长度；独立decode只读词表、编号流、共享固定形状/模式与摘要，不读原图数组，再逐图核对。每套7档各1,000图，合计14,000次独立完整图像还原通过，同一批图在各预算重复检查，不是14,000张不同图。

baseline-audit.json证明：两个数据集前256条规则完整对回旧difference-column.json，逐图token数全部等于旧E2；每个预算逐图长度随预算不增加；所有7档独立解码回执齐全。最大预算均达到150,000条，没有拿目标数冒充实际数。

CPU Idle、CPU0、各库/Rayon线程1、worker0。四阶段合计约50秒；学习/评估主进程峰值CIFAR593,166,336字节、SVHN572,850,176字节，独立解码峰值均小于153MB。启动可用内存约16GiB；进程内守护每秒检查RSS8GiB/系统余量4GiB，触线仅终止本任务并落资源失败原件，本次未触线。没有GPU或神经网络训练。

## 失败、回归与原件

新增2项合同回归检查按列索引、RGB极值/残差往返和非法展开拒绝；完整离线回归72项通过，日志 `offline-tests.log`。没有改官方代码、legacy或旧codec，无新远端CI，不提交推送。

实际原件根：`tmp/2026-11-15-rgb-large-vocab-run2/`。source为运行前源码副本，run.py保存实际装配命令；active.json/stages.json和每阶段log保留PID、耗时、退出码。dataset下含最大词表、每档JSON/NPZ、sealed-before-test.json、checkpoint、report.json及independent-decode.json。baseline-audit.json、analysis.json、table.md记录规则一致性、区间与逐档汇总。analysis的区间是事后描述，10,000次图像bootstrap、种子151506，不是新的选择标准。
