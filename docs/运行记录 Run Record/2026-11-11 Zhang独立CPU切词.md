# 2026-11-11 Zhang 独立 CPU 切词

## 结论

当前公开 Being-VL-0.5 的 BPE 核心能脱离量化器和语言模型，在 CPU 上对已有原像素整数格子学习规则并切词。未改的官方命令入口不能完整成功退出，且当前公开二维输出不能保证一般输入无损。这两项都不能外推为 2410.02155 论文整体的正确性结论。

## 来源与适配

旧 [Being-VL-0](https://github.com/BeingBeyond/Being-VL-0) 指向 [Being-VL-0.5](https://github.com/BeingBeyond/Being-VL-0.5)。固定后者提交 `e92ce36e3b8bf3e438a54a36025ecea3f8ae9170`，只下载 BPE、入口、包初始化、README 与 MIT 许可，文件哈希在 `third_party/Being-VL-0.5/SOURCE.json`。这是部分源码快照，不是安装好的整套模型，也不是旧论文固定实现。

外部包装 `src/zhang_cpu_probe.py` 直接加载未改的 `beingvl/model/vbpe.py`。运行原样 `train_vbpe.py` 时，仅把 `from beingvl import vBPE` 的包入口连接到已加载类，避免初始化导入 BeingVL 模型。没有修改类、函数或算法逻辑。像素从已有 CIFAR 压缩包直接读取，不解压、不量化，不加载模型。

## 数据与实际结果

输入为 CIFAR-10 红通道，32×32，0–255整数，规则预算256。按类别取固定前若干张，学习来自已有训练批 data_batch_1，测试来自官方 test_batch，索引保存在原始报告。学习与测试分开，测试前保留原输入副本。

| 学规则 / 测量张数 | 剩余长度 / 原长 | 外部逆合并展开失败 | 官方命令入口 |
| --- | --- | --- | --- |
| 10 / 10 | 96.73828125% | 0 / 10 | 合并完成后报 ext_vocab 不存在 |
| 100 / 100 | 95.57421875% | 6 / 100 | 此行直接调用同一官方类，不重复运行坏入口 |

两行学习规则不同，不能用相减评价更大训练样本的净收益。逆展开是外部诊断，不是作者提供的解码器。0/10不证明一般无损，6/100也不单独证明不存在其他解码办法。当前类没有完整的二维位置还原接口。

官方 `_apply_merge_2d` 会原地修改其输入视图。100张测试中13张被修改，外部始终与运行前副本比较，避免把改过的输入当真值。学习输入也被修改。第一轮二维替换之后返回一维数组，后续规则使用一维邻接，不能把这套实现描述为每轮始终保持二维几何。

## 无损性的确定反例

使用两张2×2格子，A为 `[[1,2],[3,4]]`，B为 `[[1,3],[2,4]]`。官方类在这两张格子上实际学习一条规则，得到 `(1,2)→256`。两张不同格子的官方编码输出都为 `[256,3,4]`，输入形状也相同。

因此只给当前词表、形状和序列时，不能唯一决定原格子。这个反例证明当前公开实现的该输出合同不是一般二维无损编码，不依赖外部逆展开是否足够聪明。它不证明旧论文或其他未核对版本采用相同合同。

另一个受控观察是 `[1,1,1,1]` 学不到规则：选对使用 `np.triu(...,k=1)`，排除相同编号以及行编号大于列编号的有向对。`[2,1,2,1]` 会选中其中唯一的上三角方向 `(1,2)`。这些只是当前源码行为，不修改官方实现纠正它。

## 失败与环境

原样 CLI 在 Windows 默认输出编码下先因勾选字符不能编码失败，改用解释器 UTF-8 选项后继续，实际停在 `len(vbpe.ext_vocab)`，实现对应字段是 `vbpe_vocab`。入口保存验证还使用无参数 `vBPE()`，与必需三个构造参数不符，这是静态发现，因先前失败未走到此处。

系统 Python 数值导入异常，没有修共享环境。已有隔离环境 NumPy 2.5.4 与现有 Numba 0.62.1 的 `<2.4` 要求不符。只下载 NumPy 2.3.5（12.8 MB）到指定临时目录，复用已有 Numba，现有环境文件未升级或替换。验证解释器为已有 `third_party/venv_mdbpe/Scripts/python.exe`、Python 3.13.9。此环境不是 pyproject 的固定安装验收。

所有实验设置 IDLE 优先级，Numba为1线程，其他数值线程上限8，worker=0，CUDA_VISIBLE_DEVICES为空。没有 GPU、神经网络训练或模型下载。规则学习是 BPE 计数合并，不是训练生成模型。
