普通一维 BPE 只合并相邻一对，次数小于 2 就停，并列时取字典序较小的一对，从左到右不重叠替换，新符号从 256 起。四种顺序都是 32×32 的一一对应：按行、按列、蛇形（偶数行从左到右，奇数行从右到左）、Hilbert 曲线。预算 256 和 512 是同一次学到 1024 条之后的前缀。CelebA 的普通一维在 1024 之前就停了，表里写了实际条数；其余格子都学满。

合计比特沿用第28批的口径，字典对这一组测试图只算一次。二维字典是 256 位字母表位图，加每条规则两个符号号和每个维度 6 位位移；每张图再加形状位、一个域标志，以及未知值的 literal。一维没有位移可记，字典只收两个符号号；每张图加 16 位长度和一个域标志。一维的字节本来就在 0–255 里，没有 literal。一阶估计是每张图第一个 token 的零阶熵，加上同一张图里“后一个 token 在前一个条件下”的熵，再加同一份字典和边信息。图与图之间不串联。条件表本身没有另计比特，也没有做成编码器，所以它是这串 token 的下界估计，不是压出来的文件大小。

## P14 1000 张上的比特

字典只算一次之后，1000 张上的合计比特写在 P12 各表的“1000张合计”列。三个通道、五种方法、三个预算，零阶合计都高于 zlib，也都还没有低到可以忽略原始零阶熵的程度。和预算的关系与第28批的 100 张相反：100 张上字典摊不薄，1024 条的合计比特会高于 512 条；1000 张上同一份字典摊开之后，预算从 256 加到 1024，合计比特是下降的。下降之后仍高于 zlib。绿通道蛇形 1024 条是这批零阶合计里最低的一格，7.4987，zlib 是 7.4517。

一阶估计在 P12 的 CIFAR 表最后一列。三通道都在 5.63 到 6.20 之间，低于 zlib，也低于原始零阶熵。蛇形的估计最低，按列最高，和 token 长短一致。这是用测试 token 自己的相邻对算出来的，条件分布没有另计成本。它说明 token 流里还有相邻依赖，不说明已经有一个编码器能压到这个数。

## P15 规则方向

位移是后一个锚点减前一个。第一分量是行，第二分量是列。横向是行差为 0、列差为正；纵向是列差为 0、行差为正；其余归其他。单位步是两个分量的绝对值之和等于 1。测试次数是编码时这条规则实际替换成功的次数。CIFAR 统计在 1000 张上，SVHN 和 CelebA 统计在各自的测试图上。
