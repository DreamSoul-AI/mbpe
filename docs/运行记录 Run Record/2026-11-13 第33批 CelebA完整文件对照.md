## 输入与运行

本地备份 `tmp/2026-11-12-data-results-backup/data/celeba/partial_jpg/` 有 100 张 178×218 的 JPEG，SHA-256 全部对回备份清单。备份的压缩包无法读取 ZIP 目录，现有输入未附身份映射。本批按源文件分组，从原图中心裁取 128×128（左上坐标 25、45），保留原像素间距。Pillow 转灰度后，四级取灰度整除 64，二值取灰度 ≥128。两种掩码各按格子 SHA-256 查重，100 张均未因重复或尺寸排除。固定种子 20261113，分为 24 张学习、16 张验证、32 张测试和 28 张未使用。

使用仓内 Python 3.13.9、NumPy 2.5.4、Pillow 13.0.0、psutil 7.2.2、zlib 1.3.1。实验进程和独立解码进程均为 Idle（64），绑定同一逻辑 CPU，顺序执行，数据 worker 为 0，数值库单线程。正式运行 208.3 秒，实验进程峰值工作集 1,249,325,056 字节（约 1.16 GiB），解码进程最高约 47.7 MiB。四级和二值的二维学习各耗时 43.0 秒和 45.3 秒。

## 验收与原件

每份文件由独立进程读回，逐格比较原掩码，核对解码头和编码计费。验证集共 512 次、测试集共 320 次逐图检查，失败为零。复核了每份文件 SHA-256、字节分项之和、逐图解码 SHA-256 和两种配置选择的落盘记录。全量离线回归共 50 项通过。首次回归的四个用例因 Windows 将临时目录回退到不可写路径而失败，显式将 Python 的临时目录设在仓库 `tmp/` 后通过。
