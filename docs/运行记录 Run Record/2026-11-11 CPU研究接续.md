## 证据与限制

研究记录的正式JSON摘要保存完整参数、输入索引、规则与重要结果副本，以及对应原件路径和SHA256。实验日志、原像素、中间序列与本机环境依赖仍在指定临时目录。Zhang官方源码按下载清单在运行前后核验，Elsner笔记本也在每个数据集完成后核验。

CelebA首次扩大包装提前用PIL缩放，偏离旧流程ToTensor再Resize。发现原10张没有精确对回后排除该数字，保留原件，单独重跑受影响数据集。重跑早期已经将原10张输入像素逐字节对回旧记录；CIFAR/SVHN也做了同样输入核验。过程偏差不改写成用户数据问题或官方算法失败。

修正CelebA完成后，原生形状还原失败2张。定位为第二轴裁剪偏移未保留，外部仅凭已学规则完整位移即可90/90还原。原生88/90与外部90/90分列，详细记录不隐藏失败。全部已启动实验已退出，无留待后台运行的实验。

这些结果不构成固定依赖安装验收、官方C++性能对比、完整论文复现或科学新颖性证明。没有提交推送，没有结束他人进程。只终止本线程启动且挂起的系统NumPy诊断会话，其余已启动实验由原会话跟到退出。
