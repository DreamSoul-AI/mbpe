# 第 38 批原始像素完整文件对照

2026-11-13 23:58–23:59（Asia/Shanghai）。Python 3.13.9、NumPy 2.5.4、SciPy 1.16.2、zlib 1.3.1。实验 43.74 秒，峰值工作集约 350 MiB。主进程和解码器均为 Idle，绑定一个逻辑 CPU，数据 worker 为零。

## 输入和执行

读取本机备份的 CIFAR-10 `data_batch_5`、`test_batch` 和 SVHN `train_32x32.mat`、`test_32x32.mat`。每套数据固定取 32×32 原始绿通道，训练文件内按类别抽 100 张学习、50 张验证，测试文件抽 100 张测试。格值未重映射。固定种子 38001–38003，按输入格子的 SHA-256 排除重复。源文件对回备份清单。结果适用于这两套小样本原始像素。 [事前方案](<../研究记录 Research Record/计划存档 Plan Archive/2026-11-13 第38至40批 CPU 阶段方案.md>) · [数据备份记录](<../开发记录 Development Record/2026-11-12 目录与运行产物整理.md>)

固定扫描在按行、按列、蛇形、Hilbert 中按验证集完整字节选定。自适应把总规则均分给行列，用验证集 Huffman 数据块选择邻居差阈值，zlib 共用阈值。每个数据集的词表、码表和配置写盘后再应用到测试集。格子总长每组 102,400，所有非零配置均达到规则预算。
