# 原始像素与左差分 BPE 对照

**同为 256 条二维 BPE 规则，左差分让 CIFAR-10 的测试序列再短 17.74%，SVHN 再短 28.85%。** 以每像素一个位置为基准，差分加 BPE 的总降幅分别为 23.44% 和 35.59%。

## 输入与无损验证

沿用第 38 批 CIFAR-10、SVHN 的 32×32 原始绿通道。每套 100 张学习、50 张验证、100 张测试。样本索引与逐图 SHA-256 对回原清单。两种方法分别只用学习集跑相同的二维频次算法，各得到 256 条规则、256 个基本值。原像素侧重新得到的规则、验证集和测试集逐图 token 数均与第 38 批一致。 [第 38 批运行记录](<2026-11-13 第38批 原始像素完整文件对照.md>)

差分对每行保留首像素，后续像素减左邻并取模 256。解码从保存的词表和 token 恢复差分格子，逐行累加取模 256 后与原像素逐值比较。两种方法在两套数据上均通过 50/50 张验证图和 100/100 张测试图。每行首像素已经计入序列，固定外框和覆盖顺序确定坐标，额外位置为零。

## 序列长度与输入激活

每个 token 对应一个 192 维 BF16 输入位置，占 384 字节。按单张、无批次填充换算，激活为进入第一层的输入向量张量估算。

| 数据 | 原像素 BPE → 差分 BPE 总 token | 再短 | 平均位置/图 | 平均输入激活 KiB/图 |
| --- | ---: | ---: | ---: | ---: |
| CIFAR-10 绿通道 | 95,297 → 78,395 | 17.74% | 952.97 → 783.95 | 357.36 → 293.98 |
| SVHN 绿通道 | 92,698 → 65,956 | 28.85% | 926.98 → 659.56 | 347.62 → 247.34 |

差分侧在两套测试集中各 100/100 张都比原像素 BPE 短。相对每像素一个位置，达到至少减半的图分别只有 2/100 和 3/100。最短与最长的差分序列分别为 442–945 和 481–871 个 token。

## 固定合并的长度保证

对同一批测试图，按行优先展平，把连续 $k$ 个像素用 256 进制打包成一个整数编号，尾部不足时补零，原形状确定裁掉多少。下表三种分组均逐像素还原 200/200 张。固定分组让任意长度 $N$ 的原像素序列变成 $\lceil N/k\rceil$ 个位置。

| 每位置像素数 | 每张位置 | 比 1,024 个原位置少 | 全部可能的编号 |
| --- | ---: | ---: | ---: |
| 2 | 512 | 50.00% | 65,536 |
| 3 | 342 | 66.60% | 16,777,216 |
| 4 | 256 | 75.00% | 4,294,967,296 |

整数编号可以用公式拆回多个像素。模型输入可以把这些像素分别放进同一个 BF16 向量的前几维，无需给每种组合单独存一行 embedding。整数打包的往返在本轮实测，BF16 向量直接填充的往返见固定分块试验。自由 BPE 的每图缩短量取决于合并规则实际匹配了多少位置。 [固定分块试验](<2026-11-14 固定分块的模型输入对照.md>)
