## 已知行为，不单列成缺陷

构造 `Tokenizer` 会打印 `Found codeword Sizes:`。`Reconstruct` 里原先打印内部尺寸的调试输出已经去掉。打印码字形状不改变数值，但会污染只期望 JSON 的标准输出。`plan` 不构造 `Tokenizer`，所以预览路径没有这行字。

`encode` 对非 CPU、非整数、空 batch 和不能整除的形状会失败。这是合同，不是待修的异常。

## 关闭记录

编码与解码的接口不一致、空序列上的 `argmax`、推断时频次总数为 0 的除零，都已关闭。不要把它们写回活动表。

熵指标读 `Vocab.codewords` 已于 2026-11-09 修好。原因是 `Vocab` 没有 `codewords`，只有成对的 `symbol2codeword` 和 `codeword2symbol`。改法是多样性的分母改为 `len(self.vocab.codeword2symbol)`，不新增属性，也不改 `merge_pair`。覆盖测试是 `tests/test_compression.py`。

词表不能落盘已于同日第 7 批修好。入口是 `src/mbpe/persist.py`。版本不是 1 时在构造分词器之前失败。往返测试是 `tests/test_persist.py`。编码结果文件仍未做。
