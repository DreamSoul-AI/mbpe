# 文献调研 Literature Search MBPE

## 问题与范围

截至 2026-11-12，调研集中在三个问题：二维合并何时保存了额外结构，哪些信息必须随字典与序列保存，以及怎样公平比较无损编码。以 Elsner 和 Zhang 为起点，沿几何邻接、文法压缩和压缩感知分词三组关键词追查原文。纳入能改变规则表示、基线或评价口径的工作。视觉生成和理解分数只用于说明作者实验任务。阅读位置、版本、引用量及公开实现见[论文索引](<论文索引 Paper Index MBPE.md>)，正文结构见[调研大纲](<文献调研大纲 Literature Search Outline MBPE.md>)。

## 从序列替换到多维文法

Re-Pair 已把频繁邻接对替换、递归规则展开、字典开销和序列编码放进同一压缩问题。它还比较了提前停止、解码时间与内存之间的取舍。对 MBPE 来说，频次是候选选择依据，合计比特还受符号位宽和字典开销约束。实现上的局部出现位置维护和优先队列也早已有先例。见 [Larsson 与 Moffat，§2–5](https://avadeaux.net/larsson.dogma.net/dcc99.pdf)。

Elsner 把同类思想搬到格点区域。候选的键包含两个区域的类别和锚点相对位移，同一对实例的多处接触会去重。序列按锚点输出，每个实例只写一次。解码和生成可以由已覆盖区域定位下一锚点，再用词表形状扩展。论文给出了几何数据应用，因此更高维、非凸区域和由覆盖推知位置已属于最近基线。真正需要核对的是本项目能否扩展输入合同、降低完整传输成本或证明更低的执行开销。见 [Elsner，算法 1、§4.2–4.3、§5.2](https://arxiv.org/html/2411.10281v1)。

GraphRePair 从图中识别相连的两条超边，用带连接端口的非终结边替换，并编码起始图和规则。相较于一般图，格点方案额外知道坐标、方向与固定平移关系，可以利用这些约束精确计数和保存几何。仅使用区域邻接图、优先队列或局部更新，已有直接先例。后续若研究性能，应固定规则与替换顺序，与全扫描逐轮比较，报告包含初始化、索引和峰值内存的成本。见 [Maneth 与 Peternek，§4.2–4.3、§4.6](https://arxiv.org/html/1704.05254v1)。

## 可逆性与合并目标

Zhang 2410.02155 的命题 2 采用行或列马尔可夫序列上的一维构造，评价目标是一元模型交叉熵。其 §4.1 给出视觉合并算法，附录 A.1 讨论相对 VQ 表示的额外信息损失。项目实际复核的是后来迁移公开的 Being-VL-0.5 快照。该快照首轮会把两个不同方向的 2×2 整数格子编码成同一序列，附方向位后可恢复本批输入。这给候选提供了应长期保留的反例和验收合同。见 [Zhang，命题 2、§4.1、附录 A.1](https://arxiv.org/html/2410.02155v3)及[本地反例与修复](<../../运行记录 Run Record/2026-11-11 碰撞复现与同输入对比.md>)。

后续 Being-VL-0.5 把空间一致性加入频次排序，适合用来检验“按频次选对遗漏了什么”。其 VQ 输入与下游理解任务决定了证据适用范围。另一条相邻路线是 Erdogan 等人的 LZ-aware BPE，用训练流筛候选、按验证流 gzip 大小选合并。它已经展示了按实际压缩代价选对的思路，也暴露了逐候选重编码的计算成本。MBPE 可研究的是格点条件下如何计入几何字典、有效域和边信息，并在冻结的独立测试上验证收益。见 [Zhang 等，§3.4、附录算法 2](https://arxiv.org/html/2506.23639v1)和 [Erdogan 等，§V-B](https://arxiv.org/html/2601.09039v1)。

## 对照与可复用证据

| 比较对象 | 能回答的问题 | 评价条件 |
| --- | --- | --- |
| 普通 1D BPE，按行、按列、蛇形及 Hilbert | 几何规则能否优于有竞争力的遍历顺序 | 同格子、训练和测试切分、规则预算，逐项逆展开 |
| Elsner 固定实现与项目二维候选 | 几何字典和位置合同怎样影响逐格还原 | 保留官方原件，分别登记原生输出与外部解码结果 |
| 按字节及按位打包后的 zlib | 端到端字节数对常用无损基线是否有优势 | 字典按测试批摊销，域、形状和头纳入传输成本。理论熵单列 |
| 全扫描与增量计数 | 更新方式能否降低执行成本 | 每轮规则、替换次序、输出和还原一致，再比较时间与内存 |

本地第 29–31 批已说明为什么必须保留强 1D 基线。原始自然图和原尺寸 MNIST 掩码上，二维候选未优于当时最好的一维。在第 31 批的原尺寸 bin128、1000 张学习、1024 条规则条件下，按行剩余 2.6818%，二维剩余 3.8813%。最近邻放大至 56×56 的四级数据上，二维优于当批按行对照。这个观察对应人为扩大同值区域，独立的原生高分辨率证据仍缺。见[原像素对照](<../../运行记录 Run Record/2026-11-11 第29批一维基线与二维收益.md>)、[掩码对照](<../../运行记录 Run Record/2026-11-11 第30批掩码上的一维与二维.md>)及[MNIST 对照](<../../运行记录 Run Record/2026-11-12 第31批真实二值数据MNIST上的一维与二维.md>)。

## 输入容量方向的定向补查

2026-11-14 为新研究计划补核对三个直接来源，尚未形成系统新检索。随后在 CPU 实验等待期间定向读取 [Claude、Fariña 与 Navarro，Re-Pair Compression of Inverted Lists，v1 PDF §2.2–2.3、§3.1–3.2](https://arxiv.org/pdf/0911.3318v1)。原对象是递增倒排表：先差分，再以递归相邻对规则表示；表边界禁止跨越，解码需要词典和边界定位。因而“差分+BPE”、共享词典和限制跨样本合并均有先例。可复用的是边界控制与展开机制，不能直接借用该文的压缩或检索性能到 RGB 输入。其正差分条件不同于本项目 uint8 模 256 残差。本文实验图表、代码及后续进展本轮未核验，尚不能确认图像等容量方案的研究缺口。

[PNG 第三版过滤章节](https://www.w3.org/TR/2025/REC-png-3-20250624/#filtering) 定义用已知邻域做预测及恢复的过滤过程。它提供可逆残差的工程参照，但输出文件更小不等于模型输入位置更少。[MEGABYTE v2](https://arxiv.org/abs/2305.07185v2) 的摘要说明块内局部、块间全局建模，提醒比较全局位置时还需区分块内计算。该文目前仅核对摘要，未复现模型，也未证明本项目直接字节填充具备任务效果。

新计划把固定分组设为等输入容量基线，再比较可逆变换、强一维与二维的独立作用。模型权重不属于当前输入激活主指标；共享词表和逐图额外信息仍须交代。候选贡献的最近工作覆盖、新颖性和模型可用性均待验证。 [研究计划](<../../计划 Plan/研究计划 Research Plan MBPE.md>)

## 2026-11-15 最近工作核对与本轮选择

围绕“缩短全局序列是否就是无损输入节省”“补齐优化是否仍可立方法贡献”做有界检索，纳入多尺度字节模型和序列打包的原始论文，不纳入权重量化及仅讨论 KV 缓存的结果。本轮使用 literature-search 和 paper-analysis 定向核对下列章节，未复现训练，未做穷尽检索；新增条目的引用量未查询，不能当作零。

| 直接来源与阅读范围 | 已有覆盖 | 与本项目比较的条件 |
| --- | --- | --- |
| [MEGABYTE v2，§2.1–2.4、§4.1、表7](https://arxiv.org/html/2305.07185v2) | 固定字节块、块间全局与块内局部建模；块嵌入拼接使位置减少而向量宽度变化；组件消融说明局部路径有作用 | 全局位置数不能单独当作固定宽度激活收益；本项目只验固定宽度的可逆输入，不用该文的训练/生成结果为自身背书 |
| [BLT arXiv v1，§2.1–2.4、§3.1–3.3](https://arxiv.org/html/2412.09871v1)；[ACL 2025 元数据](https://aclanthology.org/2025.acl-long.453/) | 动态字节 patch、局部编码/解码与全局潜在计算；熵模型决定边界 | 学习前端及额外字节路径与本项目固定语法不同。不能把本项目 BF16 字节填充视为已替代这些模型或已证明任务可用性 |
| [Krell 等，序列打包 v2，§3、附录C相关工作](https://arxiv.org/html/2107.02027v2) | 已研究补齐浪费、packing 与排序，并要求处理位置和注意力隔离 | 本轮只是有限窗口内排序后分别补齐，不是跨样本拼接 packing，不声称复现该文吞吐量；缓存、掩码和样本身份另列 |

进一步回读 [Elsner v1，§4.3–4.4](https://arxiv.org/html/2411.10281v1)：作者用 token 覆盖形状推知下一位置，并明确写到其简化训练按数据集最长序列补齐、删除最长的 5% 样本以减少开销。这说明补齐问题在原论文中已被识别。本轮保留全部预定样本，采用有限窗口分别补齐；它是不同条件下的本地控制，不据此声称首次发现 padding 问题。

这组证据把候选贡献收窄：减少主模型位置、多字节分组和减少 padding 都有直接先例，不能单独命名为新多维 BPE。E4 的角色是排除本地输入计费与组批疑问；E2 才用于检查当前几何词典是否超出强一维的作用。两者即使通过，仍不足以证明领域缺口或论文创新。

本轮可直接复用的是论文中的公平比较条件：固定输入宽度、保留所有字节路径、明确样本边界和辅助输入。无需加载模型权重。研究问题收窄为“冻结原生 RGB 残差表示、规则预算及向量容量后，有限窗口能保留多少净输入收益；强一维是否已经足够”，先取得可区分的 CPU 证据。任意形状的方法创新仍待理论与最近工作对照，不在本轮宣称完成。

## 当前研究判断

保持三项判据独立。先证明固定字典与 packet 足以恢复输入合同，再比较剩余 token 和合计比特，最后验证执行开销。第 29–31 批给出的负结果支持优先分析重复区域形状、字典摊销和遍历顺序。下一轮研究若要提出新贡献，应把输入合同或成本机制写成可反驳的主张，并直接对照 Elsner、强 1D 与相关文法方法。此处完成了定向调研，图压缩实验表和现代方法的实现尚未复现。研究问题和具体实验授权见[研究计划](<../../计划 Plan/研究计划 Research Plan MBPE.md>)。

## 2026-11-15 颜色与结构候选的最近来源核对

本轮沿用research-plan并用paper-analysis做定向方法阅读，目的在于界定已知机制，不是穷尽检索或证明新颖性。

- [CharLS主仓color_transform.hpp](https://raw.githubusercontent.com/team-charls/charls/main/src/color_transform.hpp)，访问2026-11-15，读取HP1正反变换及注释，未核定main提交、未编译。源码已有保留G、对R/B减G的可逆颜色变换，并明确这些变换在官方JPEG-LS规范之外。本轮使用通道重排、无128偏置的模256变体，不把该机制称为新发明，也不把它解释成真实光谱坐标。
- [Brittain与El-Sakka，Grayscale true two-dimensional dictionary-based image compression，JVCIR18(2007)35–44，作者PDF](https://www.csd.uwo.ca/~melsakka/publications/journals/pdfs/2007_jvcir_Nathanael.pdf)，读取摘要及§2.1–2.4。该文将近似块匹配与位置、尺寸、准确残差一起传输，不是只发模板就能无损。它提供参数/残差必须计费的先例；未复现实现、未核验性能表，不能借其文件收益证明本项目输入位置收益。
- [Kudo，Subword Regularization，ACL2018正式PDF §3.1–3.2](https://aclanthology.org/P18-1007.pdf)，核对固定词表下多种切分、Unigram分解和Viterbi求最优路径。路径搜索已有先例。本轮只用已有BPE词表、统一每片代价1来检查最少token，不做该文概率学习、采样或机器翻译复现。

本轮判断：可逆颜色坐标、多尺度匹配和最短路径解析都有直接已有机制。值得先取得的是相同词表预算/输入宽度下的局部证据，不能单凭组合或“hierarchical”名称宣称方法创新。颜色和模板参数若占输入位置须完整计入；静态结构共享、CPU文件缩小和模型N变少分别判断。
