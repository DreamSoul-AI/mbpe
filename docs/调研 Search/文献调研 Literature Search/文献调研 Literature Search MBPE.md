# 文献调研 Literature Search MBPE

## 问题与范围

截至 2026-11-12，调研集中在三个问题：二维合并何时保存了额外结构，哪些信息必须随字典与序列保存，以及怎样公平比较无损编码。以 Elsner 和 Zhang 为起点，沿几何邻接、文法压缩和压缩感知分词三组关键词追查原文。纳入能改变规则表示、基线或评价口径的工作。视觉生成和理解分数只用于说明作者实验任务。阅读位置、版本、引用量及公开实现见[论文索引](<论文索引 Paper Index MBPE.md>)，正文结构见[调研大纲](<文献调研大纲 Literature Search Outline MBPE.md>)。

## 从序列替换到多维文法

Re-Pair 已把频繁邻接对替换、递归规则展开、字典开销和序列编码放进同一压缩问题。它还比较了提前停止、解码时间与内存之间的取舍。对 MBPE 来说，频次是候选选择依据，合计比特还受符号位宽和字典开销约束。实现上的局部出现位置维护和优先队列也早已有先例。见 [Larsson 与 Moffat，§2–5](https://avadeaux.net/larsson.dogma.net/dcc99.pdf)。

Elsner 把同类思想搬到格点区域。候选的键包含两个区域的类别和锚点相对位移，同一对实例的多处接触会去重。序列按锚点输出，每个实例只写一次。解码和生成可以由已覆盖区域定位下一锚点，再用词表形状扩展。论文给出了几何数据应用，因此更高维、非凸区域和由覆盖推知位置已属于最近基线。真正需要核对的是本项目能否扩展输入合同、降低完整传输成本或证明更低的执行开销。见 [Elsner，算法 1、§4.2–4.3、§5.2](https://arxiv.org/html/2411.10281v1)。

GraphRePair 从图中识别相连的两条超边，用带连接端口的非终结边替换，并编码起始图和规则。相较于一般图，格点方案额外知道坐标、方向与固定平移关系，可以利用这些约束精确计数和保存几何。仅使用区域邻接图、优先队列或局部更新，已有直接先例。后续若研究性能，应固定规则与替换顺序，与全扫描逐轮比较，报告包含初始化、索引和峰值内存的成本。见 [Maneth 与 Peternek，§4.2–4.3、§4.6](https://arxiv.org/html/1704.05254v1)。

## 可逆性与合并目标

Zhang 2410.02155 的命题 2 采用行或列马尔可夫序列上的一维构造，评价目标是一元模型交叉熵。其 §4.1 给出视觉合并算法，附录 A.1 讨论相对 VQ 表示的额外信息损失。项目实际复核的是后来迁移公开的 Being-VL-0.5 快照。该快照首轮会把两个不同方向的 2×2 整数格子编码成同一序列，附方向位后可恢复本批输入。这给候选提供了应长期保留的反例和验收合同。见 [Zhang，命题 2、§4.1、附录 A.1](https://arxiv.org/html/2410.02155v3)及[本地反例与修复](<../../运行记录 Run Record/2026-11-11 碰撞复现与同输入对比.md>)。

后续 Being-VL-0.5 把空间一致性加入频次排序，适合用来检验“按频次选对遗漏了什么”。其 VQ 输入与下游理解任务决定了证据适用范围。另一条相邻路线是 Erdogan 等人的 LZ-aware BPE，用训练流筛候选、按验证流 gzip 大小选合并。它已经展示了按实际压缩代价选对的思路，也暴露了逐候选重编码的计算成本。MBPE 可研究的是格点条件下如何计入几何字典、有效域和边信息，并在冻结的独立测试上验证收益。见 [Zhang 等，§3.4、附录算法 2](https://arxiv.org/html/2506.23639v1)和 [Erdogan 等，§V-B](https://arxiv.org/html/2601.09039v1)。

## 对照与可复用证据

| 比较对象 | 能回答的问题 | 评价条件 |
| --- | --- | --- |
| 普通 1D BPE，按行、按列、蛇形及 Hilbert | 几何规则能否优于有竞争力的遍历顺序 | 同格子、训练和测试切分、规则预算，逐项逆展开 |
| Elsner 固定实现与项目二维候选 | 几何字典和位置合同怎样影响逐格还原 | 保留官方原件，分别登记原生输出与外部解码结果 |
| 按字节及按位打包后的 zlib | 端到端字节数对常用无损基线是否有优势 | 字典按测试批摊销，域、形状和头纳入传输成本。理论熵单列 |
| 全扫描与增量计数 | 更新方式能否降低执行成本 | 每轮规则、替换次序、输出和还原一致，再比较时间与内存 |

本地第 29–31 批已说明为什么必须保留强 1D 基线。原始自然图和原尺寸 MNIST 掩码上，二维候选未优于当时最好的一维。在第 31 批的原尺寸 bin128、1000 张学习、1024 条规则条件下，按行剩余 2.6818%，二维剩余 3.8813%。最近邻放大至 56×56 的四级数据上，二维优于当批按行对照。这个观察对应人为扩大同值区域，独立的原生高分辨率证据仍缺。见[原像素对照](<../../运行记录 Run Record/2026-11-11 第29批一维基线与二维收益.md>)、[掩码对照](<../../运行记录 Run Record/2026-11-11 第30批掩码上的一维与二维.md>)及[MNIST 对照](<../../运行记录 Run Record/2026-11-12 第31批真实二值数据MNIST上的一维与二维.md>)。

## 当前研究判断

保持三项判据独立。先证明固定字典与 packet 足以恢复输入合同，再比较剩余 token 和合计比特，最后验证执行开销。第 29–31 批给出的负结果支持优先分析重复区域形状、字典摊销和遍历顺序。下一轮研究若要提出新贡献，应把输入合同或成本机制写成可反驳的主张，并直接对照 Elsner、强 1D 与相关文法方法。此处完成了定向调研，图压缩实验表和现代方法的实现尚未复现。研究问题和具体实验授权见[研究计划](<../../研究计划 Research Plan MBPE.md>)。
