# 损失引导可逆 BPE 研究入口

新增 [单规则入口](../../studies/loss_guided_pair_study.py) 和 [多轮入口](../../studies/loss_guided_bpe_study.py)。单规则入口冻结互斥数据、枚举共享候选、按真实重切比较每字节损失和整图位置，并逐张独立解码。多轮入口共用数据合同和冻结预测器，在每步实际重切后维护非重叠频次和可逆词表，记录频次、损失及位置阈值对应的每次决策。模型使用 CPU 字节计数及后缀平滑。

[库版基线与独立重放入口](../../studies/loss_guided_tokenizers_check.py)复用冻结输入和预测口径。它可以直接学习标准频次 BPE，也可读取封存的合并规则，用独立的编码器验证位置数、逐目标 loss 和整图往返。

[定向回归](../../tests/studies/test_loss_guided_bpe_study.py)覆盖重复字节的合并计数、跨通道隔离、预测上下文不能读取目标，以及增量损失与显式逐前缀重切一致。代码放在研究目录，核心库接口和序列化合同沿用原实现。[实际执行和失败恢复](<../运行记录 Run Record/2026-11-17 损失引导BPE词表CPU先导.md>)
