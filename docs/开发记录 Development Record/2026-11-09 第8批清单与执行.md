# 2026-11-09 第8批清单与执行

本批做了合成清单、种子、符号上限和执行子命令。研究计划的宏观一节没有改。没有跑种子 0、1、2 的正式实验。`merge_pair` 里的 argmax、频率阈值和未知最大对停止没有改。

清单版本 1 写在 `src/mbpe/structure/synthetic_manifest_v1.json`。规则是三种固定形状 `(1, 2, 2)`、`(1, 2, 4)`、`(1, 4, 4)`，取值 0 到 7，由 `random.Random(seed)` 按形状顺序抽取。仓库不保存抽出来的格点。同一种子两次结果相同，种子 0 和 1 不同。

`TokenizerConfig.seed` 默认是 0。执行子命令的默认种子列表是 0、1、2。种子只传给清单生成，并写入该次词表的配置。没有改 Python、NumPy 或 torch 的全局随机状态，因为当前算法路径里没有别的随机调用。

符号上限字段是 `max_symbols`，默认空，训练和以前一样。计数包含初始的 256 个符号。设了上限后，新根符号写到上限为止，`merge_pair` 在下一轮选对之前返回。版本 1 JSON 会写入这个字段；旧文件没有它时按不限制读取。

`python -m mbpe plan` 仍只打印配置。`python -m mbpe run` 按种子训练、编码、检查逐格还原，并写下序列长度变化、压缩比和词表 JSON。不给 `--output` 时写到 `results/` 下按时间命名的子目录。`results/` 本来就在 `.gitignore` 里。冒烟测试只用种子 0，输出在临时目录。
