# 2026-11-10 第23批 SVHN 与 CelebA BPE

CIFAR-10 仍按第 22 批，没有量化权重就不跑。本批也不跟论文数字对差。切词用的是官方 `processor_python.ipynb` 的原文，只在内存里换数据、分辨率和额外符号个数。笔记本文件没有改。本机没有 C++ 编译器，C++ 版没有编。

两个数据集都是：32×32，官方代码只留下 ToTensor 之后的第 0 通道再乘 255，所以彩色图实际切的是红色通道，每个像素一个 0–255 的整数。原长是 32×32 = 1024。新符号从 256 号起，一共再学 256 条。长度是测试（或下面写明的测量集）上，剩余 token 数除以 1024。无损检查用官方 `resolve_token`，把序列画回格子，和切词前保存的整数图比。

张数取 50，是因为先用 10 张、1 条规则计过时，再按这个速度放大：50 张、256 条大约 20 分钟。两个数据集还要在另一批图上套规则，50 张能在时限里跑完。

## SVHN

斯坦福官方 cropped 32×32。训练包 182,040,794 字节，测试包 64,275,384 字节。下完是训练集 73257 张、测试集 26032 张。学规则用训练集里每类前 5 张，共 50 张。量长度用测试集里每类前 5 张，共 50 张，不是整个测试集。

| 项 | 结果 |
| --- | --- |
| 平均剩余长度 | 934.34 |
| 占原长 | 91.24% |
| 无损 | 50 张全部还原对 |
| 学规则 | 1167 秒 |
| 套到这 50 张测试图 | 329 秒 |

256 条里有 1 条在这 50 张测试图上没有碰上。
