# 颜色模板合同与固定词表解析

## 实现变化

本次候选与装配留在 studies，不改 src 核心、legacy 或第三方代码。

- `color_template_codec.py`：uint8 可逆颜色坐标、对齐多尺度字典学习、隐式首空位解码。相对模板额外发一个精确锚点 token；校验词表尺寸、重复项、越界、重叠、截断和尾部载荷。
- `hierarchy_color_study.py`：复用既有学习图和大词表 BPE，冻结新输入与源码，训练/封存候选，逐图编码、独立恢复、资源监控及通道关联控制；另提供固定词表均匀成本的最短解析控制，不更改 token 编号。
- `test_color_template_codec.py`：极值颜色往返、偏移模板正对照、随机噪声与混合块、非法字典/载荷拒绝。真实数据测试独立于单测。

H2 临时确认入口和快照保存在本机 tmp，四方法仅复用已经封存词表；没有为追结果改官方代码，也没有将研究原型伪装成产品接口。BPE 本来有二叉展开层次，本次并未实现神经网络的层次 embedding。

## 验证与边界

完整离线回归 76 项通过；主实验、控制及 H2 的独立恢复证据见[运行记录](<../运行记录 Run Record/2026-11-15 颜色与层次候选CPU对照.md>)。同词表最短解析逐图不长于原 BPE，并在 H2 验证；词表/编号身份与颜色逆变换同时检查。编码器 round-trip 不能代替独立解码，因此后者另起进程执行。

源码映射和研究入口同步更新。最短解析仍使用现有 tokenizers 的 Unigram Viterbi 能力，是固定词表的推断策略，不代表重做了概率训练。固定形状与隐式位置适用范围写进合同；没有扩展任意整数或任意维度。

未运行打包发布或 GPU 测试，本轮不提交推送。既有未提交的大词表工作与 .local 忽略项原样保留。[研究结论](<../研究记录 Research Record/2026-11-15 颜色坐标与多尺度词表的输入收益.md>)与[研究计划](<../计划 Plan/研究计划 Research Plan MBPE.md>)分别维护科学判断和下一步。
