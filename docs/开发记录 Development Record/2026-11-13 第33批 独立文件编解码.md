# 第 33 批独立文件编解码

研究入口冻结图像清单和划分，以同一批格子比较现有二维频次规则及四种一维遍历。写盘后调用独立进程解码，核对每张格子和完整文件成本。二维沿用候选字典与覆盖还原，一维沿用既有规则学习与替换顺序。Torch 导入移到历史转写格子读取函数，实验文件路径只依赖 CPU 上的 NumPy、Pillow 和 zlib。

文件 v1 用一个共享头描述版本、方法、边长、字母表、词表大小和样本数。新符号按规则顺序编号，规则引用位打包，二维每条另存两个有符号位移字节。每张格子使用独立 zlib 块，块头记录 token 数和压缩长度。读回时检查引用顺序、边长、解压长度、符号范围、填充和完整覆盖。格式支持 128 以内的二次幂稠密方格、二值或四级字母表和至多 256 条规则。
