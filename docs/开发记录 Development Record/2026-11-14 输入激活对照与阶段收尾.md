# 输入激活对照与阶段收尾

本轮按用户确认的输入位置和 activation 口径收尾。研究报告主表采用固定 192 维 BF16 输入，词表、参数权重和文件压缩另按实际角色记录。文本、MNIST 和原始绿通道沿用已有 CPU 结果，新增固定分块、左差分与 BPE、等容量向量打包对照。 [研究报告](<../研究报告 Research Report/2026-11-14 MBPE 研究统合报告.md>) · [最新研究结论](<../研究记录 Research Record/2026-11-14 差分BPE打包后的输入位置收益.md>)

新脚本从保存的差分词表恢复测试 token，将编号流按 9 位打包，加上两字节 token 数，按每向量前 2、3 或 192 个字节值维度装入 BF16，再解码回原像素。固定分组同样生成和读回 BF16 张量。所有配置下，CIFAR-10 和 SVHN 各 100 张逐值通过。

仓库已有的核心包结构迁移、legacy 归位、研究脚本及文档分工一并纳入本次阶段提交，入口和迁移经过保留在原日期记录。运行环境、原始数据和临时结果沿用本地忽略目录。

收尾执行 CPU 离线回归 `tests/run.py`，57 项通过，输出保存在本地 `tmp/wrapup-tests.txt`。新增打包脚本还执行了真实样本逐图还原、逐图 token 数比对与文档链接检查。GPU 实际激活峰值和任务效果待验证。
