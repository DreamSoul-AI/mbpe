# 2026-11-15 大词表一维预算实现与验证

用户要求CPU扩大一维规则预算至十几万，主目标为固定embedding宽度下减少序列输入，CPU计算与词表存储不作为否决指标。新研究入口rgb_large_vocab_study.py复用已有tokenizers原生实现，替代旧算法的词表平方计数矩阵；保持256值字母表、左差分、按列和样本/通道边界，原固定9位codec不修改。规则和词表前缀封存后再评估，uint32 token流独立保存并重建原RGB，8GiB/4GiB资源守护只约束本进程。

256条完整规则及各1,000图长度与旧结果完全一致，扩展预算的逐图长度不增；每档独立解码通过。新增两项原子/残差与失败路径回归，完整72项通过。启动引导失败和路径顺序核对失败均保留，正式运行成功原件与限制见[运行记录](<../运行记录 Run Record/2026-11-15 RGB一维规则预算扩展CPU对照.md>)。

研究计划和开发计划按用户要求优先大词表曲线，研究记录修正“自然RGB弱缩短”仅适用于256预算的范围。d192不变，变化的是N；词表变大可能换输入activation收益，lookup表参考单列，不假称测过模型总显存。所有改动留工作区，不提交、不推送、不建PR。
