# RGB 词表覆盖对照与固定尺寸解码

[研究脚本](../../studies/raw_rgb_coverage_study.py)装配嵌套学习集、预算前缀、独立测试和隐式通道边界解码。拟合只读学习数组。评估复用普通 BPE 或等成本 Viterbi，保存编号序列及每图长度。解码按词条展开确定通道边界并核对原图哈希。差分与颜色采用既有可逆模块。

新用例核对截断、尾部、跨通道无效载荷、合并顺序与最少 token 差别，并验证三种表示恢复原始 RGB。完整离线回归 81 项通过。真实数据另外完成 138,000 次方法×图片独立恢复。实现放在 studies。
