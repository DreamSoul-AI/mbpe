# 第 35 批配对格子实验入口

新增批次入口，将同一份区块标签分别铺成 4×4 方块和 1×16 长条。生成器在交给规则学习前核对逐值计数与格子去重，保存标签、整体偏移、转置和逐图哈希。正式运行前从清单标签独立重建了 72 对格子，核对了两种铺法和各集合一半转置。

同一布局下，二维和 Hilbert 各学习一次到 256 条，再按固定前缀比较 64 与 256 条。复用已有频次学习、规则应用、实际替换分类、zlib v1 与 Huffman v2。独立解码后核对每张格子的原始字节和 SHA-256，并检查文件大小、读回 token 和字节分项。配对统计保留每对的差值，重采样时共享词表和码表各计一次。
