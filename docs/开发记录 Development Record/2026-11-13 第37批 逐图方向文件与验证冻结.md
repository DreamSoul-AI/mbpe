# 第 37 批逐图方向文件与验证冻结

新增 `MBPA` 研究文件。文件先写统一尺寸和预算、按行与按列两套词表、Huffman 所用的两张码长表和逐图一位的方向标记，再写各图独立数据块。解码器根据文件里的方向选择词表、码表和扫描顺序，从文件独立恢复按行排列的整数格子。沿用已有 `MBPE` 格式的定宽打包、Huffman、zlib 数据块和一维网格还原逻辑。

主实验复用第 35、36 批文件并校验来源，验证集选向规则写盘后才计算测试图分数。补充入口复用同一阈值，把原方向词表各截成一半以对齐总规则数。两种入口都核对独立解码、逐项 token、打包计费和逐格哈希。
