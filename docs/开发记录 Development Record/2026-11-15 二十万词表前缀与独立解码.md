# 二十万词表前缀与独立解码

新增 `studies/color_vocab_extension.py`，复用既有颜色双射、差分、按列原子与独立展开，提供 train/evaluate/decode 三阶段预算扩展。每种表示在同一学习集学至 20 万合并后取两档前缀，全部候选封存再读取测试。前 15 万词条及编号与旧词表完全相同，逐图长度也逐项相同；固定词表最短解析逐图不长于合并顺序。

测试载荷仅保存 token IDs，独立端按展开长度确定固定通道边界，无需 per-channel counts。实际 16,000 次独立恢复通过，脚本前缀恒等、词表/载荷摘要、输入身份及尾部完整性检查通过。未改既有 codec、核心、官方或 legacy，本次不重复之前的 76 项回归，也未提交推送。

详细数据、资源及命令见[运行记录](<../运行记录 Run Record/2026-11-15 二十万规则与文本长度对照.md>)，科学归因见[研究记录](<../研究记录 Research Record/2026-11-15 文本图像同宽位置与二十万规则.md>)。研究入口和源码映射同步新增预算扩展职责；共享临时原件仍在 Git 忽略的 tmp。
