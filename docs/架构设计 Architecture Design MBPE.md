# 架构设计 Architecture Design MBPE

## 目标和阶段

MBPE 的当前目标是在有限整数格点上学习 BPE 规则、编码和逐格还原，并让一维扫描、Elsner 基线和任意形状候选可以同口径比较。可安装的张量 BPE 已按职责归入 structure 和 flow，任意形状候选仍在研究脚本中。科学依据见[文献调研](<调研 Search/文献调研 Literature Search/文献调研 Literature Search MBPE.md>)。工程比较见[通用调研](<调研 Search/通用调研 General Search/通用调研 General Search MBPE.md>)。

## 两柱与研究边界

| 部分 | 职责 |
| --- | --- |
| structure | 表达格点与规则、词表、编码、计数、切分、还原、配置、指标和持久化合同。部件可独立调用，保持确定的算法与数据语义。 |
| flow | 解析 CLI 参数、装配结构部件、执行合成运行和既有对照、选择输出位置并保存运行结果。 |
| studies | 按课题组合官方基线、候选和输入准备，保留独立实验身份与版本。 |
| tests | 验证核心部件、流程和研究脚本各自的合同，并用离线运行覆盖实际入口。 |
| src/legacy | 保存历史实现与示例，用于追查来源。 |

包根的两个 Python 入口分别服务导入和 `python -m mbpe`。业务实现归两柱。允许 flow 依赖 structure，studies 可调用所需核心能力。核心包的导入和安装独立于 studies、legacy 和第三方实验目录。

## 数据流和状态

```mermaid
flowchart LR
  CLI["CLI 或研究入口"] --> F["流程装配与执行"]
  F --> S["配置、规则、词表与编解码"]
  S --> M["长度、位成本、逐格核验"]
  M --> R["运行输出与版本证据"]
```

学习阶段可更新词表、合并顺序与频次。编码和解码使用已定词表。现有张量实现输出 `TensorEncoding`，其 shape、dtype、顺序和整除条件保持。任意形状候选的有效域、字典位移、未知整数和 packet 另有实验合同。候选进入正式包之前需明确输入范围、序列化版本及复现门槛。

完整文件对照由研究入口装配。首版格式覆盖稠密二值和四级方格，后续增加逐图方向标记及 `MBPG` 整数格点格式。`MBPG` 保存共享字典、形状、有效域、未知整数和逐图数据块。第 40 批由独立进程从文件恢复非方形、带孔和三维格子，覆盖边界输入。该路径位于 `studies/`。 [格式实现与验证](<开发记录 Development Record/2026-11-14 第38至40批 整数格子文件与验证.md>)

运行流程支持配置预览、合成 BPE 和已存在的对照。预览必须可在不加载 Torch 时生成 JSON。运行结果需带输入身份、规则预算、版本和还原检查。实验的 token 长度、完整位成本和解码失败分别登记。资料归属见[文档导航](README.md)。

## 迁移与验收

职责迁移已完成。离线回归覆盖合成 CPU 往返、顺序和并列、持久化 v1、符号上限和 CLI 入口。支持环境中的安装冒烟单独验收。研究算法、计分和输出格式的改变独立立项。具体模块映射和测试结构见[代码结构设计](<代码结构设计 Code Structure Design MBPE.md>)。
