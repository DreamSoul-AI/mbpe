## 本轮交付与接续

### 本轮不少于 30 分钟的执行安排

最近工作及研究计划已先校准：常见组批优化不作为方法创新。本轮由用户授权自主实现和运行，完成两份计划时记录计时起点，至少持续 30 分钟，不为凑时间重复已有批次。

| 顺序 | 预计工作段 | 必须产出的实际交付 |
| --- | --- | --- |
| 1 | 前约 5–10 分钟 | D6 组批合同与新切分入口，定向测试；旧原件与词表只读复用 |
| 2 | 随后约 10–15 分钟 | 新验证/测试冻结，真实 CPU BF16 batch 和独立恢复，验证选择封存后一次性测测试 |
| 3 | 余下及必要延长 | 补 D3 强一维或处理失败；完整回归、配对分析、研究/运行/开发记录 |

这是工作量安排，不是虚构已测时长或硬性切断作业；依据实测耗时调整。完成 E4 后仍有时间就继续预定 E2，达到 30 分钟后完成正在执行的必要验证再收尾；不结束任何他人进程，不提交或推送。

2026-11-15 下列 D1/D2/D3/D4/D6 已完成本轮固定 RGB 范围，D5 尚未实施。当前主待办回到研究计划的 E3 合同核查，D7 保留为峰值控制候选。按新研究计划调整优先级。研究主线目前返回补查文献、识别候选缺口及校准宏观目标，尚未确立新的论文方法贡献。已完成 E1 的 D1/D2 和 D4 基础能力保留；下面登记本轮交付与后续合同，本轮实现顺序为组批入口先于强一维，不表示已经完成立题或自动启动实验。实验目的、判据及何时修订路线仍由研究计划维护。

| 顺序与研究依赖 | 需要实现什么 | 工程验收 |
| --- | --- | --- |
| D6 → E4，本轮完成 | 新验证/测试排除清单、有限窗口稳定排序、CPU BF16 batch、样本顺序恢复和缓存/辅助张量计费 | 输入窗口 W=16/64/128；原顺序与排序均保持样本双射和逐格还原；实配字节与统计相符，等长阴性对照不产生假收益；只按验证集选择 |
| D1 → E1/E2 | 新 RGB 输入清单与排除旧样本；只用学习集建立共享词表；配置和验证选择快照 | 检查源身份、切分不相交及重复内容；相同清单可重建输入；加载测试集前冻结配置，拒绝覆盖旧快照 |
| D2 → E1 | 拆分可逆左差分、RGB 通道边界、9 位流打包与 192 维 BF16 输入核算，复用已有候选和打包部件 | uint8 极值、首列、RGB 顺序、跨字节和跨容量尾部均往返；计入 6 字节 RGB token 数；独立端只用共享字典和完整载荷还原 |
| D3 → E2 | 按行/按列/蛇形/Hilbert 的等容量入口，与二维共享输入、变换、预算和计费 | 与二维采用相同通道边界；验证选向和并列顺序确定；不读取测试结果选方法；保留每图 token 与位置分项 |
| D4 → E1/E2 | 图像配对汇总、组批补齐计量、资源日志与续跑 | 总位置等于逐图求和，384L 等于输入张量字节；批次计量按实际补齐长度；重启只复用身份和配置均匹配的完成项 |
| D5 → E3 | 掩码因果预测、未知整数表示及完整输入合同 | 空域、孔洞、非方形、三维和未知值均恢复；截断、无效编号及重复覆盖明确失败；任意整数不能套用 uint8 模运算 |

D1/D2 已支持固定 32×32 RGB 主协议并通过运行验收；D4 已有逐图汇总、组批计量、资源日志、源码快照和阶段检查，仍不支持学习循环内部的检查点续跑。D3 强一维已通过定向合同、独立测试及共同 FIFO 张量验收；D5 任意形状预测仍待实现。绿通道诊断组本轮未单跑。不要把固定 RGB 合同写成任意输入都已支持。具体职责见[架构设计](<../../设计 Design/架构设计 Architecture Design MBPE.md>)与[代码结构设计](<../../设计 Design/代码结构设计 Code Structure Design MBPE.md>)。候选保持在 `studies/`，不预先并入核心包，不修改官方实现或 legacy。

D6 已实现有限窗口稳定排序、实配 batch、mask/长度、独立序列化解码和缓存分项；E4 已完整 CPU 运行并独立解码通过；E2 也已完成，科学结果不支持本场景的二维优势，E3 未执行。新的方案选择快照需要同时登记入队种子、词表、计费合同及批次规则；不能只冻结原图或只核对 token 数。

## E4 后触发的候选，暂未实施

E4 的累计输入改善没有降低最大单批输入。因此 D7 候选为按真实输入字节预算决定批大小：固定 98,624 字节上限、最多 16 图、保留全样本，测试超限拆批和等长退化，分开报告累计分配、最大单批与批次数。它服务研究计划的 E5，不把“实现预算约束”当作科学新颖性。E2 已不支持当前二维优势，下一项待实施为 D5 的最小可逆预测合同，D7 是否继续须由研究价值和峰值需求决定；当前没有 D7 代码或执行证据。

## 内存边界与暂缓项目

用户最新明确跨数据集暂时不做，撤回 D8 的跨数据集共享词表、混合组批与联合学习排期；这些没有实现、没有运行。仅保留单数据集内的按需读取、有限缓存和过程内 RSS/系统余量检查需求，扩大前先做小样本内存冒烟。

现有 ND 学习器保留全学习集的区域及出现位置索引，尚非流式学习器。不能用加载迭代器掩盖学习状态开销。默认单进程、worker=0、每库线程=1；初始任务 RSS 预算约 2 GiB、系统可用内存保留 4 GiB，运行前核定，触线停止扩量或缩小缓存。以上保护尚未实现，不冒称已有硬限制。

## 验证与交付

针对新增非平凡逻辑在 `tests/studies/` 增加合同和失败路径回归，再执行受影响的检查及项目离线验收入口；文档调整只核对结构、链接、编码与事实。新研究运行独立登记环境、命令、输入、配置、结果及未覆盖项，不能用测试通过代替研究假设成立。

从最新 `development` 派生 `codex/` 任务分支。提交、推送与合并按当前任务授权执行；已配置的 CPU CI 仍按[仓库约定](<../../../REPO.md>)运行，不因计划更新就声称远端验证通过。模型接入、GPU、训练、量化和大下载不属于本阶段工程交付。

## 已完成：大词表一维预算曲线

新增studies/rgb_large_vocab_study.py，复用历史tokenizers原生CPU实现避免平方计数矩阵；按研究协议冻结256至150000规则前缀，单列旧实现256差异。负责共享字典、逐图编号流、独立解码和内存守护。输入activation为384×token数；embedding词表容量参考单列，不以CPU时间或词表文件大小否决长度收益。该任务优先于E3/D5，跨数据集仍暂缓。每档写checkpoint，正式数值须有独立还原回执。

大词表接口、7档前缀、逐图/独立还原及内存守护已实现验收，完整72项回归通过；未做GPU/模型吞吐或新提交。研究下一步由大词表结论中的覆盖问题决定，不能自动回到原先E3排期。

## 当前自主执行：颜色坐标与多尺度模板

实现studies中的可逆颜色坐标、固定多尺度模板合同与配套实验装配；两参数的相对模板必须计两个embedding位置，禁止把形状和颜色免费合并成一个普通ID。独立新测试清单冻结并排除旧批次；复用15万BPE强基线。先写变换和模板完整性测试，再做固定候选验证/测试及独立还原。阶段原件、失败、进程资源保存；本轮不提交推送。约30–40分钟安排和科学判读见研究计划新协议。
