# MBPE 计划入口

| 当前文档 | 回答的问题 |
| --- | --- |
| [研究计划](<研究计划 Research Plan MBPE.md>) | 研究贡献、已有证据、问题与猜想、最小验证及判读 |
| [开发计划](<开发计划 Development Plan MBPE.md>) | 支撑研究需要实现什么、依赖什么、怎样验收 |

研究计划与开发计划分别维护。研究计划从结论选择下一步，具体执行事实进入[运行记录](<../运行记录 Run Record/>)，实现变化进入[开发记录](<../开发记录 Development Record/>)。

[计划存档](<计划存档 Plan Archive/README.md>)保留旧计划和已执行批次的事前方案；已完成协议不再堆入当前计划。研究结论仍从[研究记录](<../研究记录 Research Record/README.md>)进入。
