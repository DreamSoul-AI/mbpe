# 原始 RGB 大词表的独立长度收益

## 三个问题的直接回答

1. **不做差分、颜色变换或最短切分，大词表有效吗？有效。** 原始 RGB 普通一维 BPE 在 20 万规则时，CIFAR-10 平均减少 **49.79%** 输入位置，SVHN 减少 **58.65%**，全部逐图无损。
2. **原始 RGB 也达到了七至八成吗？没有。** 该水平来自另外加入的表示变换和解析改进，不能归给大词表本身。
3. **15 万加到 20 万还明显提升吗？本轮增幅小。** 原始 RGB 两集分别多省 0.534/0.525 个百分点。学习池固定各 1000 图，不能断言其他规模也饱和。

## RQ1：原始像素的普通 BPE 到底能省多少？

每张图原长为 3×32×32=3072 个通道值。表中“减少比例（平均 token 数）”，数字全在同一 H2 测试集上逐图配对；旧条件只核对原件，未重跑或改变规则。

| 处理及解析方式 | CIFAR 15万 | CIFAR 20万 | SVHN 15万 | SVHN 20万 |
| --- | ---: | ---: | ---: | ---: |
| 原始 RGB＋普通一维 BPE | 49.26%（1558.803） | 49.79%（1542.402） | 58.13%（1286.345） | 58.65%（1270.206） |
| 左差分＋普通一维 BPE | 56.80%（1327.008） | 57.09%（1318.292） | 69.51%（936.660） | 69.95%（923.131） |
| 颜色变换＋左差分＋普通一维 BPE | 66.47%（1030.179） | 66.95%（1015.177） | 76.65%（717.420） | 76.93%（708.821） |
| 颜色变换＋左差分＋最短切分 | 70.33%（911.339） | 70.84%（895.765） | 79.43%（631.851） | 79.70%（623.700） |

新原始 RGB 条件不做量化、差分或颜色变换，不用最短路径解析。R/G/B 各通道按列展开为 1024 个值，共用一个普通 BPE 词表；没有跨通道或跨图合并。把 uint8 值映射到 256 个互异符号仅为学习器输入，不改变数值与频次。每种数据集只用同一 1000 张学习图建词表，先学到 20 万规则，再取 15 万前缀；两档编号一致，实际分别得到 150,256/200,256 项词表。

测试继续使用相同 H2 各 1000 图，与学习集独立、旧实验已曝光，是用户指定的配对消融，不能称作新抽取的独立确认。前端扫描、通道顺序和尺寸全固定；未针对原始 RGB 在测试集挑扫描方向，因此不是所有一维扫描的最优值。

## RQ2：这些长度能对应输入 activation 吗？

在共同 192 维 BF16、一个 token 一个向量且未补齐的合同下，可以按 384T 字节核算输入；原始每图 1152 KiB。原始 RGB 的新结果如下：

| 数据 | 规则数 | 平均 token T | 位置减少 | 至少减半的图片 | 输入 KiB/图 |
| --- | ---: | ---: | ---: | ---: | ---: |
| CIFAR-10 | 150,000 | 1558.803 | 49.26% | 316/1000 | 584.55 |
| CIFAR-10 | 200,000 | 1542.402 | 49.79% | 376/1000 | 578.40 |
| SVHN | 150,000 | 1286.345 | 58.13% | 934/1000 | 482.38 |
| SVHN | 200,000 | 1270.206 | 58.65% | 948/1000 | 476.33 |

**CIFAR 的平均值接近减半，但仍未达到 50%。** SVHN 平均缩短约 59%；均值不表示每张图都有同样比例。共享固定尺寸与通道顺序已知，解码依词条展开至每通道 1024 个值确定边界，不需要免费夹带 token 数、颜色、方向或坐标。变尺寸/模式时另行计费。

所有新条件逐张恢复原 RGB 字节；另起进程只用词表和 token IDs 独立恢复，共 4000 次方法×图片检查通过，实际为 2000 张不同图片。没有将一个向量塞多个编号，没有计算文件节省，也没有使用 GPU 或训练网络。上述输入核算不等于整网实测峰值。

## RQ3：如何修正当前判断？

### 最短切分是什么意思

词表固定后，同一段原始值可能有多种合法切法。普通 BPE 按学得的合并优先级执行，不保证该词表下 token 数最少；最短切分是在不增加任何词条、不改变编号的条件下，选 token 数最少的完整覆盖。实现用统一每词成本的 Viterbi 路径搜索，不是简单“每次挑最长词”。

例如词表除单字符外含 BC、AB、CD，合并顺序是先 BC、后 AB、再 CD。输入 ABCD，普通 BPE 得到 `A | BC | D`（3 个 token）；最短切分得到 `AB | CD`（2 个）。两者准确还原同样内容，词表完全相同，只是切法不同。本机用既有 tokenizers 构造该例并验证上述输出。这是解释性例子，不是图像实验结果或新颖性证明。

这种选择不会增加词表，搜索成本在本轮 CPU 编码端；没有测其吞吐或证明神经网络效果。它优化给定词表下的位置数量，不等同于最小文件比特数，也没有重新训练概率模型。

应明确区分四层收益：原始值的大词表 BPE；在此之外做左差分；再变换颜色；最后换同词表解析。这里是按固定顺序递加的消融，不能将相邻差值理解为所有组合下的独立、可相加效应。

原始 RGB 结果表明，不需要先变换像素也能大幅减少位置。因此，早期小预算“原始像素几乎不缩短”只能是当时条件下的结论，不是无损图像 BPE 的上限。但当前纯原值方案仍比文本既有约 77–78% 的降幅低，且二者原始单位、学习量和前端不同；不能将跨领域表当成等信息量的算法排名。
