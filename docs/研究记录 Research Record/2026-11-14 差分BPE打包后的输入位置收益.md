# 差分 BPE 打包后的输入位置收益

同一向量容量下，差分 BPE 在这两套图上仍带来额外的位置收益。计入 9 位编号和每图 token 数之后，CIFAR-10 比每 2、3 个像素固定分组分别再少 **13.59%、13.70%** 的位置，SVHN 分别再少 **27.24%、27.33%**。两边用相同的 192 维 BF16 输入向量，每维装一个字节值，额外信息和尾部补齐均计入。 [逐图还原与计费](<../运行记录 Run Record/2026-11-14 差分BPE等容量向量打包.md>)

固定分组先减少位置，再用可逆差分与 BPE 利用重复模式，这两部分的收益可以在本次设定下叠加。三维容量时，CIFAR-10 从 342 降到平均 295.13 个位置，SVHN 降到 248.54，输入激活分别从 128.25 降到 110.67 和 93.20 KiB/图。每档两种方法均逐像素还原全部 200 张图。

本结论适用于第 38 批固定的 32×32 单通道小样本，以及上轮仅由学习集得到的 256 条差分规则。每图都缩短尚未实现，CIFAR-10 在两维和三维容量时各有 8 张没有额外缩短。用满 192 维时，固定分组为 6 个位置，差分 BPE 分别为平均 5.07 和 4.41。模型实际激活峰值、学习效果、RGB 整图及更大测试集仍待验证。 [原差分实验](<2026-11-14 左差分与固定分组的序列长度结论.md>)
