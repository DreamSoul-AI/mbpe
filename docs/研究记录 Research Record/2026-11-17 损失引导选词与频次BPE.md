# 损失引导选词与频次 BPE

## 两个核心问题

1. **实际重切的 loss 能否为选词提供额外信号？** 能，在本次 CIFAR-10 的冻结字节计数模型上观察到信号。同一频次档的候选在两组测试上给出不同的 loss，部分差异伴随压缩收益取舍。
2. **是否胜过常规频次 BPE？** 在单 token 计数预测器上，64 和 128 条规则时相对库版频次 BPE 有小幅收益。改用两个 token 的预测器后，两项的共同收益未重现。实际神经模型尚未验证。

## 同一批候选可以量出什么

在 32 个共享单规则候选中，频次最高的组只有 `00 00` 满足打分集的位置门槛，两支选中同一条。它在首批测试平均少 165.45 个位置，在复核平均少 170.32 个位置。

有多个候选的频次档中，`fd 00` 与频次首选 `fd fc` 的差异重现。每字节 loss 分别再低 0.000681 和 0.000799 nats，同时每图少省 2.19 和 0.84 个位置。首批少省约 17%，超过打分集采用的 15% 选择窗口。其余两档的优势未在两组同时稳定重现。按图配对区间与所有候选可从运行原件核对。[运行记录](<../运行记录 Run Record/2026-11-17 损失引导BPE词表CPU先导.md>)

三档有多个位置匹配的候选，档内各有 5–8 条规则。打分集的实切 loss 排序与两组测试的实际 loss 排序 Spearman 相关为 0.67–0.90。用频次排序得到 −0.63 到 +0.37。档内样本量很小，这项结果支持 loss 给出额外排序信号。

## 多轮能否超过频次选词

在 64 条规则、读取最后一个 token 的条件下，两组各 500 张上，loss 选词相对本项目非重叠频次基线每图分别少 1.16 和 0.78 个位置，每字节 loss 分别低 0.00203 和 0.00195 nats。与库版常规频次 BPE 比，两组分别少 0.91 和 1.40 个位置，loss 分别低 0.00104 和 0.00152 nats。两项配对区间在两组均低于零。实际位置收益约为基线的 0.04%–0.06%。

早期 32 条规则在相同两组上，loss 选词相对非重叠频次基线每图多用 2.04 和 2.90 个位置，每字节 loss 分别低 0.00046 和 0.00060 nats。这种取舍说明单步保留至少九成的长度收益，不能保证任意最终预算同时升高两项表现。

| 新增规则 | 两组位置差（每图） | 两组 loss 差（nats/字节） | 判断 |
| ---: | ---: | ---: | --- |
| 64 | −0.91 / −1.40 | −0.00104 / −0.00152 | 两组的两个指标配对区间均低于零 |
| 128 | −2.85 / −2.65 | −0.00193 / −0.00266 | 结果重复，输入位置约再少 0.13%–0.14% |
| 256 | −1.39 / −0.62 | −0.00132 / −0.00259 | loss 下降重复，第二组的位置差区间跨零 |

128 条规则相对本项目的非重叠频次基线，每图位置差为 +0.01 / +0.90，loss 变化为 −0.00300 / −0.00273。256 条规则的位置差为 −0.59 / +0.88，loss 变化为 −0.00143 / −0.00224。由此，较稳定的信号是入表规则能改变这类模型的预测 loss。额外位置收益很小，而且依赖选用哪个频次实现作基线。

词表内容确实发生变化。单 token 实验的 256 个新增词条中，两支重合 207 个，loss 分支选入 49 个频次分支未选的字节串。双 token 实验重合 215 个。这些字节串随词表固化，解码只需 ID 到字节串的映射及共享变换。

## 换一个预测器后是否仍成立

改为读取末尾两个 token 后，64 条规则两组每图少 0.56 / 0.16 个位置，loss 变化为 −0.00007 / +0.00034 nats/字节，各区间均跨零。128 条与 256 条规则分别多用 3.25 / 3.82 和 1.73 / 2.19 个位置，loss 区间仍跨零。这个对照用同一套非重叠频次基线、数据和候选筛选门槛，说明单 token 结果对模型能利用的上下文敏感。两组各 500 张在所有对照逐图核对通过。

## 适用范围

已测范围为可逆颜色差分 CIFAR-10、一维按列扫描、逐通道、共享词表。计数模型通过末尾 token 的展开取字节上下文，合并可让同样数量的 token 覆盖更多原始字节。真实神经模型的长期预测、生成质量和设备峰值显存仍待验证。固定 192 维 BF16 下，每增减一个输入位置对应 384 字节张量。

若继续验证，先用固定的真实下游预测模型重做少量位置匹配的规则对照，分开测冻结模型和允许同预算适应时的结果。两种条件下的预测损失与位置收益将决定是否值得扩大词表学习。
