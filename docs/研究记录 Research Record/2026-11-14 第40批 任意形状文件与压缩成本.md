# 第 40 批任意形状文件与压缩成本

## 总览

1. **本批的矩形、带孔域和三维格子能从文件恢复吗？** **是。** 50 个文件共 1,700 次独立逐图检查通过，覆盖标量、空域、零边长及未见的大整数。
2. **几何 BPE 的实测文件比线性扫描小吗？** **否。** 三种布局的非零规则文件都由线性扫描更小。三维 256 条时，几何 BPE 少 329 个 token，计入位移后 Huffman 多 633 字节、zlib 多 427 字节。
3. **已在原生稀疏数据上验证压缩排序吗？** **尚未验证。** 本批的压缩对照来自 CIFAR-10 裁块和人为挖孔。 [运行记录](<../运行记录 Run Record/2026-11-14 第40批 任意形状文件与线性对照.md>)

## 分项证据

### 形状和有效域能独立恢复

- **依据。** 线性和几何方法从文件读回各轴长度、有效格点和整数。带孔组的两种文件均支付 3,840 字节的位图。边界组还原了空标量、零边长、空域和超过 64 位的未见整数。
- **适用范围。** 有限整数格点文件，包括本批的 0、2、3 维输入。词表按秩建立，Huffman 和 zlib 都验证了逐格还原。
- **待验证。** 更大外框和高稀疏度下的域成本，以及更高维或不同轴语义的数据。 [字节分项与验收](<../运行记录 Run Record/2026-11-14 第40批 任意形状文件与线性对照.md>)

### 几何规则的位移有实际压缩成本

- **依据。** 三维 RGB 256 条时，几何 Huffman 数据块少 135 字节，词表多 768 字节位移，完整文件多 633 字节。zlib 的数据块少 341 字节，完整文件多 427 字节。三维 64 条 Huffman 的字节差区间跨零。
- **适用范围。** 每轴位移用有符号变长整数存储，文件每组共用词表并按图分块。线性扫描由验证集从三种路径选定。
- **待验证。** 针对常见轴向位移优化存储或按实际字节收益选规则，能否跨过完整文件的差额。 [规则、文件与配对区间](<../运行记录 Run Record/2026-11-14 第40批 任意形状文件与线性对照.md>)
