# 第 38 批真实像素上的扫描与二维

## 总览

1. **64 和 256 条规则下，自动选向比固定扫描省文件吗？** **否。** 两套原始绿通道的 Huffman 和 zlib 文件都更大。零规则 zlib 未见稳定差距。
2. **同样两档规则下，二维比固定扫描省文件吗？** **否。** 两套数据的文件均更大。SVHN 64 条的二维少 6 个 token，Huffman 文件仍多 117 字节。
3. **所有完整文件都能逐格还原吗？** **是。** 36 个文件全部通过。两套输入均为 32×32 原始 8 位绿通道小样本。 [运行记录](<../运行记录 Run Record/2026-11-13 第38批 原始像素完整文件对照.md>)

## 分项证据

### 固定扫描在本批的非零规则对照中更小

- **依据。** 256 条时，CIFAR-10 固定、自动和二维 Huffman 文件依次为 101,166、102,356、102,046 字节，SVHN 为 100,386、102,180、100,920 字节。两套数据、两档规则与两种后端的配对区间均支持固定扫描更小。
- **适用范围。** 固定扫描按验证集在四种路径中选择。自动选向只在按行和按列间选，每方向分一半规则。该结果同时包含了词表分配及扫描选择的成本。
- **待验证。** 真实低字母表、原生标签或更大尺寸输入上，方向自适应能否有净收益。 [文件与区间](<../运行记录 Run Record/2026-11-13 第38批 原始像素完整文件对照.md>)

### 零规则的 zlib 优势需要控制位宽

- **依据。** 两套数据零规则用 8 位，非零规则用 9 位。CIFAR-10 固定扫描 zlib 为 96,355 对 109,182 字节，SVHN 为 87,487 对 106,469 字节，比较的是零规则与 256 条。
- **适用范围。** 当前定宽打包及逐图 zlib，字节含完整开销。
- **待验证。** 在相同打包位宽下，零规则与非零规则的差额还能保留多少。 [运行记录](<../运行记录 Run Record/2026-11-13 第38批 原始像素完整文件对照.md>)
