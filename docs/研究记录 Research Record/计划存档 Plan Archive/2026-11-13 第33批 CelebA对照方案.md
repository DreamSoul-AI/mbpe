# 第 33 批 CelebA 对照方案

归档时第 33 批已完成。正文保留执行前的研究问题、方案和判读标准。 [正式运行记录](<../../运行记录 Run Record/2026-11-13 第33批 CelebA完整文件对照.md>)

## 目标与当前判断

在 Elsner 等人的多维 BPE 基础上，研究适用于任意形状整数格点的无损 BPE，找出可验证的改进。这里的任意形状包括不同维数、不同边长和带孔的有效域。当前范围是 CPU 上的整数格点 BPE、逐格还原和压缩评估，执行约束见[仓库约定](<../../../REPO.md>)。

已有候选在跨维数、带孔域和小域穷举中通过往返检查。Zhang 后续公开快照存在方向丢失造成的同序列碰撞。Elsner 的官方实现有形状导出偏移缺失的反例。论文已涵盖多维、非凸形状和按覆盖推断位置，后续贡献要落在可明确比较的能力或成本上。 [无损候选验证](<../../开发记录 Development Record/2026-11-11 无损候选设计与验证.md>) · [Zhang 碰撞](<../../运行记录 Run Record/2026-11-11 碰撞复现与同输入对比.md>) · [Elsner 导出反例](<../../运行记录 Run Record/2026-11-11 第27批 Elsner形状导出最小例.md>) · [文献调研](<../../调研 Search/文献调研 Literature Search/文献调研 Literature Search MBPE.md>)

当前优先验证**二维 BPE 在未经缩放的图像格子上，能否压出比最佳一维 BPE 更小的无损文件**。第 32 批的放大四级 MNIST 上，二维胜过按行，Hilbert 尚未对比。112×112 二值上，Hilbert 在三档预算下都胜过二维。第 30 批合成图则出现过二维省 token、估算总比特反而更高的情况。下一轮要测的是重复二维结构省下的流字节，能否抵消词表和几何位移的成本。 [阶段结论](<../../研究记录 Research Record/2026-11-13 多维BPE阶段结论.md>) · [第 32 批运行记录](<../../运行记录 Run Record/2026-11-13 第32批MNIST放大尺度对照.md>)

## 下一轮实验

**拟议，尚未执行。** 先用本地 CelebA 备份小试。从原尺寸图像取中心 128×128 区块，保持像素间距。沿用现有灰度转换，四级（灰度整除 64）是主设置，二值（灰度 ≥128）用于辅助判断。两种设置用同一批图，逐格还原目标是各自的整数格子。 [掩码定义](<../../运行记录 Run Record/2026-11-11 第30批掩码上的一维与二维.md>)

1. **固定样本。** 核对原图尺寸、来源和身份元数据，拟用 24 个学习、16 个验证、32 个测试来源，种子 20261113。身份可用时每个身份取一张并隔离划分。否则按源文件划分并排除完全重复输入，结论限于所测文件。保存样本清单、输入哈希和裁剪坐标。
2. **固定对照。** 冻结现有二维频次规则，与按行、按列、蛇形、Hilbert 四种一维 BPE 共用输入和划分。比较 0、64、256 条规则的前缀并记录实际条数。二维选预算，一维选顺序和预算，Hilbert 单列。各方法都在验证集按完整文件字节数选配置，再用独立测试集评估。0 条规则和打包 zlib 提供两项参照。 [二维候选](<../../../studies/lossless_nd_candidate.py>) · [一维规则学习](<../../../studies/batch30_mask_baselines.py>) · [遍历实现](<../../../studies/batch31_mnist.py>)
3. **先检查文件，再比较压缩。** 小样本先验证仅凭落盘文件能独立解码，检查形状、有效域、每格的值和字节分项。各方法共用文件结构、样本边界和同版本同级别的 zlib。BPE 对照先打包 token，打包 zlib 直接压缩原整数格子。每份文件计一次词表，并计入位移、形状、有效域、未见值、文件头和解码所需字段。先测小样本用时与峰值内存，再确定运行规模。沿用 CPU 最低优先级，线程至多 8、数据 worker 至多 4。

## 判读与后续

**主指标是测试文件总字节数，逐格还原全部通过后才比较。** 同时报告每格比特、token 数、长条与紧凑块的实际替换次数、各项字节、用时和峰值内存。估算熵用于解释历史结果。打包 zlib 的结果单列。

以「二维总字节减最优一维总字节」为差值。按独立来源配对重采样，拟用固定种子和 10,000 次抽样估计 95% 区间，每次计一次词表与文件固定开销。区间全低于零支持二维更省，全高于零支持一维更省，跨零或来源独立性不足时保留为未定。任何还原失败先排查并保存反例。

- **完整文件更小。** 用原生二值文档标注或其他整数标签格子独立复核，按原始文档分组。之后用尺寸和值频一致的紧凑块、长条对照，检查收益是否来自可重复的二维结构。
- **只省 token，或完整文件更大。** 先区分位移字典和 token 流开销。如果几何成本是瓶颈，再测试按传输成本选合并或决定何时停止，并保留独立测试集。
- **结果未定。** 先查样本独立性、字典摊销与方差来源，据此决定是否补数据。局部计数提速留作独立工程问题，以规则、替换顺序和解码一致为前提。 [既有边界图试验](<../../运行记录 Run Record/2026-11-11 任意维表示与边界图小试验.md>)
