# 左差分与固定分组的序列长度结论

## 总览

1. **先做左差分，能让同预算的二维 BPE 再缩短多少？** CIFAR-10 再短 **17.74%**，SVHN 再短 **28.85%**。两套各 100 张测试图都比直接切原像素更短，且逐像素无损还原。
2. **能做到每张图都少 50%–70% 的位置吗？** 固定分组可以。把每 2 或 3 个像素放进一个位置，32×32 单通道图的位置分别少 **50.00%** 或 **66.60%**。当前 256 条规则的差分 BPE 仅有 2/100 张 CIFAR-10 和 3/100 张 SVHN 达到减半。

## 左差分的收益适用于什么输入

同一批 32×32 原始绿通道，两边分别用同一套二维算法学习 256 条规则。CIFAR-10 平均从 952.97 降到 783.95 个 token/图，SVHN 从 926.98 降到 659.56。以每像素一个位置为基准，两套图的总降幅分别为 23.44% 和 35.59%。每行的首像素已计入序列，固定外框和覆盖顺序足以恢复坐标。 [实验设置与逐图验收](<../运行记录 Run Record/2026-11-14 原始像素与左差分 BPE 对照.md>)

按每个 token 一个 192 维 BF16 向量、单图无填充估算，CIFAR-10 的输入激活从 357.36 降到 293.98 KiB，SVHN 从 347.62 降到 247.34 KiB。全彩整图、其他分辨率和实际 GPU 激活峰值仍待验证。 [长度与输入激活](<../运行记录 Run Record/2026-11-14 原始像素与左差分 BPE 对照.md#序列长度与输入激活>)

## 固定分组给出了什么基准

已知原长时，每 $k$ 个像素固定分成一组，长度为 $\lceil N/k\rceil$。1,024 个像素用两像素一组是 512 个位置，用三像素一组是 342 个位置。两档均在这 200 张图上验证了整数打包后逐像素还原。位置降幅由分组大小和尾部补齐决定。扩大 BPE 词表能覆盖更多组合，每张图能缩短多少仍取决于实际匹配。 [固定分组验收](<../运行记录 Run Record/2026-11-14 原始像素与左差分 BPE 对照.md#固定合并的长度保证>)

还待验证的是，同样允许一个向量容纳多个值时，差分 BPE 能否在固定分组的基础上进一步减少位置，以及模型能否用好这种输入。 [固定分块的 BF16 还原](<../运行记录 Run Record/2026-11-14 固定分块的模型输入对照.md>)
