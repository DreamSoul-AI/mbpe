# 多维 BPE 早期实验结论

本页汇总截至第 28 批的主要发现。第 29–32 批的对照见[多维 BPE 阶段结论](<2026-11-13 多维BPE阶段结论.md>)。

## 总览

1. **官方 BPE 能缩短已测原像素的序列吗？** **是。** MNIST 灰度剩余 18.52%，三个彩色数据集也缩短了序列，早期结果来自小子集。CIFAR 上的三种新计分都未改善第 27 批主对照的测试长度。
2. **候选在已测小域、带孔域和未见整数上通过逐格还原了吗？** **是。** 这些是候选的往返结果。指定版本的 Zhang 方向碰撞与 Elsner 形状导出偏移另有反例。
3. **增量计数在 CIFAR 小试中保留规则并提速了吗？** **是。** 两个自有 Python 实现选出相同规则和最终区域，增量版的规则学习更快。峰值内存和更广输入上的表现尚未验证。

| 对照 | 结果与适用范围 |
| --- | --- |
| 原像素上能缩短多少 | Elsner 官方规则在 500 张 28×28 MNIST 灰度图上学习 256 条，套用到 10,000 张测试图时，平均剩余长度为 18.52%。逐格还原证据来自小样本和单元检查。早期三个彩色数据集的结果来自小子集。 [四数据集结果](<2026-11-10 第25批 四数据集结果表与Zhang可行性.md>) |
| MNIST 的历史差距排查 | 当时在原始灰度测试集上，用笔记本和 C++ 分别得到 18.52% 和 17.78%。跳过灰度零、改变统计字段、扫描规则预算等已测设置都未对上旧记录中的论文图 6 数字。论文那一格的实际生成配置仍未核实。 [第 17 批测量](<../开发记录 Development Record/2026-11-10 第17批 MNIST压缩率口径与测试集.md>) · [第 21 批排查](<../开发记录 Development Record/2026-11-10 第21批 MNIST差距收尾.md>) |
| 官方输出能否逐格还原 | 固定 CIFAR 三通道各 1000 张的同输入对照中，Elsner 原生还原均通过。Zhang 后续公开快照出现横竖方向碰撞，另存第一轮方向后可恢复本批输入。Elsner 另有形状导出反例，CelebA 原生 88/90，用完整位移外部解码为 90/90。 [同输入对照](<../运行记录 Run Record/2026-11-11 碰撞复现与同输入对比.md>) · [Elsner 扩大测量](<../运行记录 Run Record/2026-11-11 Elsner扩大灰度测量.md>) |
