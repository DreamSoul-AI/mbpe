## 受限环境下核对实际临时目录

2026-11-14 本机回归中，PowerShell 设置 TEMP/TMP 后，沙箱仍在子进程重写这两个变量，Python 的 `tempfile` 退回 C 盘并触发访问拒绝。设置命令本身不能证明临时目录已生效。需要限制落盘位置时，在实际 Python 测试进程中核对 `tempfile.gettempdir()`；本次在进程内绑定仓库 tmp 及 `tempfile.tempdir` 后，原来的 4 项环境错误消失，完整 63 项通过。 [验证与适用环境](<../开发记录 Development Record/2026-11-14 RGB等容量输入实现与CPU验证.md>)

此做法适用于已确认会重写环境变量的受限启动链，不要求普通项目全局修改 tempfile，也不替代子进程自己的目录核验。保留首次失败，避免将权限错误误判为算法缺陷或为通过测试放宽系统权限。此项尚未交 workspace 采纳。
