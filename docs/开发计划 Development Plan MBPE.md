## 保持的行为

下面这些是当前合同，不是待办。

- 合并分数仍是次数除以总次数，取序列里第一次达到最大的那一对。
- 这一对不在词表中就停止，不改去合并更低频率的已知对。
- 重叠从左向右消耗。
- 位置只存在于 token 顺序。不附加下一块坐标，也不附加覆盖区域的位置编码。
- 初始字母表仍是 `(1, 1, 1)` 上的 0 到 255。
- `plan` 只打印 JSON。

[合成格点微观对照](<运行记录 Run Record/2026-11-09 合成格点微观对照.md>)记录了会改变 token 数的因素，供后续对照设计参考。

## 不在本队列里

- 不把 `legacy/tuple`、`legacy/pipeline` 和现在的张量实现合并成一个算法。
- 不把官方 MDBPE 或 Being-VL 仓库克隆进本仓库，也不把它们的训练流程写成下一张工单。
- 不扫描空间项的 α 和 σ。2026-11-09 只用了论文里的一组默认值。
- 不把压缩比写成门槛。它在多样性缺陷修好后只作为报告指标，仍不含词表正文和位置的传输成本。
- 不升级 `pyproject.toml` 里固定的 numpy、torch、tqdm 版本。声明环境是 Python 3.10 到 3.12。已有运行记录使用的是本机 Python 3.13.9 和 torch 2.11.0+cu130，那次通过不能代替按声明版本安装后再验收。
